# Laptop Notch — downloads

A dynamic notch for your laptop: music with synced lyrics, notifications, a file shelf,
quick access, weather, meetings, clipboard history, system info and more, in a notch at the
top of your screen.

## Get it

| | |
|---|---|
| **Windows (recommended)** | [Microsoft Store](https://apps.microsoft.com/detail/9NL5JMSC56M5) (includes notifications in the notch) |
| Windows (direct) | `Notch_x.y.z_x64-setup.exe` from the [latest release](../../releases/latest) |
| macOS (Apple silicon + Intel) | `Notch_x.y.z_universal.dmg` from the [latest release](../../releases/latest) |
| Linux | `.AppImage` or `.deb` from the [latest release](../../releases/latest) |

Installed apps update themselves from this repository (Settings › About › Check for updates).

This repository only holds release files. The source code is private.
